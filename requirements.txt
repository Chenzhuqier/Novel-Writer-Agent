# v0.2 新增依赖说明：
#
# 本项目核心改进不引入新的 Python 依赖包，
# 所有改进均在代码层面实现：
#
# 1. Token 追踪          → 内置 TokenTracker 类
# 2. 多模型路由          → 内置 MODEL_ROUTING 配置
# 3. JSON 强约束         → 使用 OpenAI SDK 原生 response_format
# 4. 版本控制            → 内置 VersionedStoryBible 类
# 5. 上下文压缩          → 内置 ContextCompressor 逻辑
# 6. 流式输出            → 使用 Flask Response + SSE
# 7. 反馈重写机制        → 流水线逻辑改进
#
# 可选扩展（如需向量语义检索 RAG）：
#   pip install -r requirements-rag.txt   # sentence-transformers（本地中文嵌入）
# 然后在 .env 设置 ENABLE_VECTOR=on 启用；未启用时自动回退到原有手工上下文/子串匹配。
